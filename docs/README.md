## 📦 Deployment

The documentation can be deployed to:
- **GitHub Pages** - Automatic deployment via GitHub Actions
- **Netlify** - Connect repository for continuous deployment
- **Vercel** - One-click deployment
- **Any static hosting** - Upload `.vitepress/dist/` contents

### GitHub Pages Example

```yaml
# .github/workflows/docs.yml
name: Deploy Docs
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
        working-directory: docs
      - run: npm run docs:build
        working-directory: docs
      - uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: docs/.vitepress/dist
```

## 🛠️ Development

### Adding New Pages

1. Create markdown file in appropriate directory:
   - User docs: `en/` or `de/`
   - Architecture: `en/architecture/` or `de/architecture/`
   - API: `en/api/` or `de/api/`
   - Implementation: `en/implementation/` or `de/implementation/`

2. Add frontmatter:
```markdown
---
title: Page Title
description: Brief description
outline: deep
---
```

3. Update navigation in `.vitepress/config.mts`

4. Create German translation in corresponding `de/` directory

### Local Development Tips

- Hot reload is enabled (changes appear immediately)
- Use `:::tip`, `:::warning`, `:::danger` for callouts
- Code blocks support syntax highlighting (typescript, gdscript, bash, etc.)
- Link to other pages: `[text](./other-page.md)`
